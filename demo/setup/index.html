Set up the card

The card needs Home Assistant 2023.9 or newer and any weather integration. It asks for no account or key.

Install

With HACS

Open in HACS

The button opens the card in HACS on your own Home Assistant. Install iWeather Card, then reload your browser. To add it by hand instead:

  1. In HACS, open the ⋮ menu and choose Custom repositories.
  2. Add https://github.com/sitapix/iweather-card with the type Dashboard.
  3. Install iWeather Card, then reload your browser.

By hand

  1. Download every file from the latest release, or build them with Node 22.18 or newer and pnpm: 
    pnpm install --frozen-lockfile
pnpm build   # writes them to dist/
  2. Copy them all to one folder, such as /config/www/iweather/. The card loads its clouds, moon, map and editor languages from beside its own file.
  3. Go to Settings → Dashboards → ⋮ → Resources and add /local/iweather/iweather-card.js as a JavaScript module.

Browsers keep the old file after an update. Change the resource's address to load the new one, for example /local/iweather/iweather-card.js?v=2.

Add it to a dashboard

Choose iWeather in the card picker. It starts on the page layout, with one of your weather entities, and every option is in its editor. In YAML, the entity is all it needs:

type: custom:iweather-card
entity: weather.home

The page layout shows everything once it has a few more settings:

type: custom:iweather-card
entity: weather.home
weather_layout: page
place_name: St. Louis
averages: open-meteo
map: rainviewer

A tile with nothing to show hides itself, so you can start small. The editor's Data sources section marks the readings your weather entity leaves out, and a sensor of your own can stand in for any of them.

Put the page layout in a panel view and it fills the screen. As you scroll, the conditions shrink into a band at the top and the panels pass under it.

Layouts

weather_layoutShows
autoWhatever fits the space the dashboard gives it. The default.
compactA short tile: the place and temperature over the conditions and the day's high and low.
stripOne line: the place, the temperature and the conditions.
expandedThe conditions, the hourly forecast and the daily list.
pageEverything: alerts, forecasts, a map and detail tiles, in two to six columns.

What it asks of the internet

The auto, compact, strip and expanded layouts talk to Home Assistant alone. The page layout can fill what your weather entity leaves out from Open-Meteo, show radar from RainViewer, and in the United States show the National Weather Service's alerts. Your browser asks each one itself. Set local_only: true and the card asks none of them.
