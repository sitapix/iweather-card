Set up iWeather Card

You’ll need Home Assistant 2023.9.3 or later and a weather entity, such as weather.home. The card works with any weather integration and needs no API key.

Install the card

Install with HACS

Open the repository with the button above, install iWeather Card, then reload your browser.

If you’re adding the repository yourself, open the ⋮ menu in HACS and choose Custom repositories. Enter https://github.com/sitapix/iweather-card, select Dashboard, and add the repository. You can then install the card in HACS.

Install manually

  1. Download the card files attached to the latest release. If you’re building from source, run these commands in the repository with Node.js 22.18 or later and pnpm. The build writes the files to dist/. 
    pnpm install --frozen-lockfile
pnpm build
  2. Copy all the files into one folder, such as /config/www/iweather/. The card looks there for its images, map and translations.
  3. In Settings → Dashboards → ⋮ → Resources, add /local/iweather/iweather-card.js as a JavaScript module. Reload your browser.

When you update a manual installation, copy the new files and change the version in the resource URL, for example to /local/iweather/iweather-card.js?v=2. This makes the browser load the new card.

Add the card to a dashboard

Edit your dashboard, select Add card, then choose iWeather. The picker starts with Full page and suggests a weather entity. Check that it’s the one you want, then save.

If you prefer YAML, replace weather.home with your entity ID in the example below. With just these two lines, the card uses the Automatic layout and fits the space on your dashboard.

type: custom:iweather-card
entity: weather.home

For a full page with radar and historical averages, use this configuration. Change the town and entity to match your forecast.

type: custom:iweather-card
entity: weather.home
weather_layout: page
place_name: St. Louis
averages: open-meteo
map: rainviewer

Tiles appear when they have data. Open Data sources in the editor to see which readings your weather entity is missing and choose sensors to supply them.

Online data and privacy

Full page can send the forecast location to Open-Meteo for missing readings, air quality and climate averages. In the US, it can also fetch alerts from the National Weather Service. The online map requests radar, forecasts and map tiles for the area in view. Your browser contacts these services directly. The other layouts get their weather from Home Assistant.

Set local_only: true to turn off the built-in online services. To show a map in this mode, supply a base map with map_tile_url. Use local servers for both the base map and any map_layers overlays to keep tile requests on your network. See which services receive location data.
